# 💊 لوحة متابعة مبيعات الصيادلة

لوحة تحليلات **تعمل بالكامل في المتصفح** لمتابعة مبيعات الصيادلة يوميًا من تقرير
**«مبيعات أصناف المورد» (PDF)** الصادر من نظام الصيدلية.

## الفكرة باختصار
1. كل يوم تُصدِّر من النظام تقرير «مبيعات أصناف المورد» بصيغة PDF.
2. تفتح اللوحة (`index.html`) وتسحب الملف داخلها (أو تضغط «رفع تقرير اليوم»).
3. اللوحة تقرأ الملف تلقائيًا، تستخرج **اسم الصيدلي + اليوزر + الأصناف + الكمية المباعة
   + قيمة البيع + التكلفة**، وتحفظها **على جهازك** حسب **تاريخ التقرير**.
4. كل يوم تُضيفه يتراكم، فتشوف: **مين أكتر واحد باع**، اتجاه كل صيدلي، وأداء كل صنف
   عبر الأيام والشهور.

## المميزات
- **رفع يومي** لملف واحد أو عدة ملفات مرة واحدة (سحب وإفلات).
- **إعادة رفع نفس اليوم تُحدِّث بياناته** (لا تكرار) — المفتاح هو تاريخ التقرير.
- **لوحة ترتيب الصيادلة** حسب قيمة البيع / الكمية / الربح، مع فلترة بالفترة والبحث بالاسم.
- **الاتجاه اليومي** لإجمالي المبيعات، و**اتجاه كل صيدلي** على حدة (اضغط على اسمه).
- **تحليل الأصناف**: مبيعات كل صنف وأكثر صيدلي باعه.
- **سجل الأيام** مع إمكانية حذف يوم رُفع بالخطأ.
- **تصدير / استيراد** نسخة احتياطية (JSON) لنقل البيانات بين الأجهزة أو أرشفتها.
- تعمل **بدون إنترنت** بعد أول فتح (PWA)، وقابلة للتثبيت على الموبايل والكمبيوتر.

## الخصوصية
كل البيانات تُخزَّن محليًا في متصفّحك (`localStorage`) — لا تُرسَل لأي خادم.
لنقلها لجهاز آخر استخدم زر **تصدير** ثم **استيراد**.

## التشغيل
- الأفضل تشغيلها عبر خادم (GitHub Pages أو أي استضافة) حتى يعمل الـ Service Worker
  وقارئ الـ PDF بشكل كامل. مثال محلي:
  ```bash
  cd sales && python3 -m http.server 8080
  # ثم افتح http://localhost:8080
  ```

## بنية ملف الـ PDF (كما فهمها المُحلِّل)
التقرير مُجمَّع حسب **المستخدم (الصيدلي)**، ولكل صنف سطر بالأعمدة:

| العمود | المعنى |
|---|---|
| كود المستخدم | يوزر الصيدلي (مثال: `107003`) |
| المستخدم | اسم الصيدلي |
| اسم/كود المادة | الصنف (مثال: `NOSTRIDERM` — `1-09-118-050`) |
| الكمية المباعة | عدد الحبات المباعة |
| القيمة بسعر البيع | قيمة البيع (﷼) |
| قيمة التكلفة | التكلفة (﷼) |
| الكمية الحالية | رصيد المخزون (غير مستخدم في التحليل) |

يُقرأ **تاريخ التقرير** من سطر «من تاريخ / إلى تاريخ»، وتُتجاهَل صفوف
«إجمالي المستخدم» و«إجمالي الحركة».

> تم التحقق من دقة المُحلِّل بمطابقة مجاميعه لسطر «إجمالي الحركة» في التقرير المرجعي:
> **41 حبة · 2,175.00 بيع · 253.25 تكلفة · 26 صيدلي**.

## الملفات
| الملف | الوظيفة |
|---|---|
| `index.html` | اللوحة والواجهة |
| `parser.js` | مُحلِّل تقرير الـ PDF (بالإحداثيات) |
| `sw.js` | Service Worker للعمل بدون إنترنت |
| `manifest.webmanifest` | إعدادات التطبيق القابل للتثبيت |
| `vendor/` | مكتبة `pdf.js` والأيقونات (محليًا، بدون إنترنت) |
