# PharmaDash

لوحة تحليل محلية لملفات كتابات الأطباء بصيغ Excel وCSV وPDF. الإصدار النهائي يظل ملف HTML واحدًا قابلًا للفتح في المتصفح، بينما المصدر والاختبارات منفصلة لتقليل أخطاء التعديل اليدوي.

## الاستخدام

1. حمّل `PharmaDash-v3-medical-ready.html` (اسم الملف محفوظ للتوافق؛ محتواه هو PharmaDash v4).
2. افتحه من خادم محلي أو استضافة HTTPS لضمان عمل Web Crypto وملفات PDF بصورة مستقرة:

   ```bash
   python3 -m http.server 8123
   ```

3. افتح `http://localhost:8123/PharmaDash-v3-medical-ready.html`.
4. ارفع ملف الفرع من بطاقات T1/T2/T3. تتم المعالجة والتخزين محليًا في المتصفح.

يمكن نشر ملف HTML نفسه على أي استضافة ملفات ثابتة تدعم HTTPS ليعمل كتطبيق ويب دون Backend. ملفات المرضى لا تُرفع إلى الاستضافة؛ يقرأها متصفح المستخدم محليًا. لا تنشر ملف مشاركة يحتوي بيانات كاملة على رابط عام.

## الخصوصية

ملفات الكتابات قد تحتوي بيانات مرضى حقيقية. لا ترفع الملف أو ملف المشاركة إلى خدمة عامة. التخزين المحلي (`IndexedDB`) غير مشفر بواسطة التطبيق، لذا يجب استخدام جهاز مشفر ومغلق. تسجيل الدخول داخل ملف HTML هو حاجز استخدام محلي وليس مصادقة خادم.

الوضع الافتراضي للتصدير والمشاركة مجهول الهوية. راجع الوجهة يدويًا قبل استخدام وضع «بيانات كاملة حساسة». زر «مسح» يزيل بيانات الوصفات والمتابعة والإعدادات التجارية المحفوظة، مع إبقاء تفضيل المظهر فقط.

## صيغ الرفع

- Excel (`xlsx`/`xls`): يبحث عن ورقة البيانات تلقائيًا ويحافظ على تنسيق أرقام المرضى والطلبات.
- CSV: يدعم UTF-8 وUTF-16 وWindows-1256.
- PDF: يدعم تقارير PDF النصية ذات رؤوس عربية أو إنجليزية، بما في ذلك العناوين المجزأة وبعض الأسطر الملفوفة.
- PDF المصوّر: يحتاج OCR أولًا؛ لا يمكن استخراج بيانات موثوقة من صورة بلا طبقة نص.

الحدود الحالية: 50MB للملف، 500,000 صف للرفع، 1,000 صفحة PDF، و150MB للقطة التخزين. راجع لوحة جودة البيانات بعد كل رفع، وجرّب أول ملف فعلي مع عينة معروفة قبل الاعتماد على النتائج.

النسخة المحمولة ليست Offline بالكامل: الخطوط وChart.js وSheetJS وPDF.js تُحمّل من CDN، ولذلك يلزم اتصال عند فتحها لأول مرة.

## التطوير

```bash
npm install
npx playwright install chromium
npm run build
npm run test:unit
npm run test:e2e
npm run verify
```

يتطلب التطوير Node.js 22 أو أحدث. المتصفحات المستهدفة هي الإصدارات الحديثة من Chrome/Edge؛ يلزم HTTPS أو `localhost` لسلامة Web Crypto وIndexedDB.

مصدر الحقيقة:

```text
src/PharmaDash.template.html  HTML shell
src/styles.css                styles
src/app.js                    dashboard application
src/core/index.mjs            tested core utilities
scripts/build.mjs             builds the portable HTML
```

ينتج البناء ثلاثة ملفات متطابقة:

- `PharmaDash-v3-medical-ready.html`
- `pharmdash v3 medical.html` (اسم توافق)
- `dist/PharmaDash-v3-medical-ready.html`

لا تُعدّل الملفات المولدة يدويًا؛ عدّل `src/` ثم نفّذ `npm run build`.
