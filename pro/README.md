# PharmaDash Pro — متابعة الأصناف والأطباء

نسخة مبسّطة ومعاد هيكلتها من PharmaDash، مبنية حول فكرة واحدة: **اضغط على أي حاجة تشوف كل تفاصيلها.**

| الصفحة | اللي فيها |
|---|---|
| الرئيسية | أرقام سريعة، كروت أصنافي، واقتراحات: (محتاجين زيارة · فرص جديدة · توقفوا عن الكتابة) |
| أصنافي | كروت الـ 13 صنف (NOSTRI + PureHerb)، وبحث في كل الأدوية المكتوبة (ومنها أدوية المنافسين) |
| صفحة الصنف | مين بيكتبه وكام مرة، وفين (الأقسام والتعاونات)، وتطوّره مع الوقت، ونسبة الصرف، والمبيعات الفعلية لو رفعت ملف المبيعات |
| صفحة الطبيب | كل الأدوية اللي بيكتبها، وأصنافي منها، والأصناف اللي لسه ما كتبهاش (مرتّبة حسب كتابة زملائه في نفس القسم)، وسجلّ زياراته |
| الزيارات | تسجيل زيارة (الأصناف اللي اتكلمت عنها، ملاحظات، ميعاد الزيارة الجاية)، و«أثر الزيارة» = كتاباته قبل الزيارة وبعدها، وتصدير Excel |
| البيانات | رفع تقارير الروشتات (Excel أو CSV أو PDF) لكل تعاون بتاريخها، وملف المبيعات JSON، ونسخة احتياطية واسترجاعها |

- كل البيانات بتتحفظ على الجهاز نفسه (IndexedDB)، ومفيش أي حاجة بتترفع لأي سيرفر.
- قارئ الملفات (`engine.js`) منقول زي ما هو من PharmaDash Pro 3.5، فنفس التقارير بتشتغل.
- الصفحة جاهزة تبقى تطبيق (PWA): فيها `manifest.webmanifest` و`sw.js`، وبتشتغل من غير إنترنت بعد أول فتح.
