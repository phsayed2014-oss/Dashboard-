# PharmaDash — تطبيق قابل للتثبيت (PWA)

هذا المجلد يحوّل لوحة PharmaDash إلى **تطبيق قابل للتثبيت** على الموبايل والكمبيوتر،
ويشتغل حتى بدون إنترنت بعد أول فتح.

## المحتويات
| الملف | الوظيفة |
|------|---------|
| `index.html` | الداش بورد نفسها (نسخة PharmaDash مع دعم التثبيت) |
| `manifest.webmanifest` | إعدادات التطبيق: الاسم، الأيقونات، الألوان، وضع ملء الشاشة |
| `sw.js` | Service Worker — يخزّن الملفات للعمل بدون إنترنت |
| `icons/` | أيقونات التطبيق (192 / 512 / maskable) |

## التثبيت المباشر
- **أندرويد (Chrome):** القائمة ⋮ ← «تثبيت التطبيق / إضافة إلى الشاشة الرئيسية».
- **آيفون (Safari):** زر المشاركة ⬆️ ← «إضافة إلى الشاشة الرئيسية».

## توليد ملف APK حقيقي
1. انشر المجلد على **GitHub Pages** (Settings ← Pages).
2. افتح <https://www.pwabuilder.com> والصق رابط التطبيق `.../dashboard-/app/`.
3. اختر **Android ← Generate Package** ونزّل ملف `.apk`.

> صفحة التعليمات الكاملة بالعربي: `app-install.html` في جذر المستودع.
